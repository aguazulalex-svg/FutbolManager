# ⚽ FutbolManager

Aplicación móvil desarrollada con Flutter y Firebase para la administración de torneos de fútbol.

## Descripción

FutbolManager busca facilitar la organización y el seguimiento de competiciones de fútbol mediante una aplicación que centraliza la información de los equipos, jugadores y partidos.

## Funcionalidades

* Registro e inicio de sesión.
* Administración de equipos.
* Registro y consulta de jugadores.
* Programación de partidos.
* Registro y actualización de resultados.
* Tabla de posiciones.
* Registro de goleadores y tabla de máximos anotadores, según las funcionalidades implementadas.
* Almacenamiento y consulta de información mediante Firebase.

## Tecnologías utilizadas

* Flutter
* Dart
* Firebase Authentication
* Cloud Firestore
* Visual Studio Code
* Git y GitHub

## Requisitos

* Flutter instalado.
* Dart compatible con la versión de Flutter utilizada.
* Visual Studio Code o un editor compatible.
* Acceso a un proyecto de Firebase configurado para la aplicación.

## Instalación

1. Clona este repositorio.

2. Abre la carpeta del proyecto en Visual Studio Code.

3. Ejecuta:

   ```bash
   flutter pub get
   ```

4. Configura Firebase con las credenciales y los archivos necesarios para tu propio entorno.

5. Ejecuta la aplicación con:

   ```bash
   flutter run
   ```

## Configuración de Firebase

Para ejecutar la aplicación, configura un proyecto de Firebase compatible con la plataforma que desees utilizar. No publiques credenciales privadas, contraseñas ni claves de servicio.
